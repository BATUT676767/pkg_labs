# Цветовые модели — лабораторная работа №1

**Вариант 2: RGB ↔ CMYK ↔ HLS.**

Приложение позволяет выбирать цвет из палитры, вводить его компоненты числами и изменять их ползунками. Все три представления одного цвета обновляются автоматически.

## Запуск

Откройте `index.html` в современном браузере. Установка зависимостей, сборка и сервер не требуются. Файлы `model.js`, `view.js` и `controller.js` должны находиться рядом с HTML.

Для переноса одним файлом можно использовать `Цветовые_модели_вариант_2.html`: разметка, стили и скрипты включены в него.

## Работа с цветом

- Числовой ввод и ползунки для всех компонент RGB, CMYK и HLS.
- Системная палитра и готовые образцы в каждой модели.
- Открытая двумерная палитра с выбором насыщенности и светлоты, отдельная полоса тона.
- Ввод HEX, отображение текущего цвета и RGB.
- Алгоритмы цветоделения GCR и UCR с настройкой силы замены серого.
- Выбор белой точки D65, D50 или E для внутренних XYZ/LAB.
- Clipping и Scaling для обработки RGB вне диапазона.
- Динамические градиенты, предупреждения о некорректном вводе и адаптивное расположение элементов.

Все преобразования реализованы на JavaScript без библиотек конвертации. XYZ/LAB рассчитываются дополнительно и доступны через `Controller.getColorimetry()`; отдельных полей XYZ/LAB в интерфейсе нет.

## Проверка математики

При установленном Node.js выполните из папки проекта:

```bash
node -e "const fs=require('node:fs'); const vm=require('node:vm'); const r=vm.runInNewContext(fs.readFileSync('model.js','utf8')+'\n'+fs.readFileSync('tests.js','utf8')+'\nrunColorTests()'); console.log(r); if(r.passed!==r.total)process.exit(1)"
```

Набор содержит 1523 проверки: эталонные цвета, обратные преобразования HLS и CMYK, UCR/GCR при нескольких значениях силы замены, белые точки, XYZ/LAB и обработку диапазона. Тесты не подключены к основной странице.

Описание формул и принятых решений приведено в [отчёте](report.md).
